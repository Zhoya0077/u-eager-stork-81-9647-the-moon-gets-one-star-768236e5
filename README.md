# The Moon Gets One Star

One-star review of the Moon, 120 characters or fewer. Run it and it writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`):

```sh
node main.ts
```

## Entry

> ★☆☆☆☆ Moved my entire ocean twice a day without asking. No notice, no permit, and it still expects worship.

The grievance is Moon-only: the Moon drags the ocean around twice a day (tides) with no notice and no permit — then still expects worship. A real one-star review shape (rating, grievance, punchline), no craters, no cheese, no brightness joke.
